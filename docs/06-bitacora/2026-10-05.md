# 2026-10-05 · Definición del proyecto y setup

## Qué se hizo

1. **Definición del proyecto** mediante una entrevista estructurada (preguntas por rondas con opciones y recomendación):
   - Objetivos: trabajo, freelance y marca personal, además de la etapa final de ISI802.
   - Stack: primero se propuso Astro y luego se evaluaron React, Svelte y Vue. Ganó Astro sin framework de UI ([decisión 001](../03-decisiones/001-astro-sin-framework-ui.md)).
   - Contenido: un JSON por sección ([decisión 002](../03-decisiones/002-json-por-seccion.md)).
2. **Guía de diseño** iterada en 8 versiones de un mockup HTML interactivo:
   - Dos variantes iniciales: *Terminal* (mono, ámbar) y *Minimal* (grotesca, lila). Se eligió Terminal con la nav en píldora de Minimal.
   - Prueba de acentos (cian y otros), hasta que el autor definió la dirección final: negro puro, vidrio estilo Tidal/Vercel, bento grid, partículas multicolor y guiños a power metal, juegos de estrategia y gacha.
   - Se agregaron sliders para calibrar. Valores finales: paleta **Sangre**, brillos **20%**, blur **20px**, partículas **100%** ([tokens](../04-diseno/tokens.md)).
   - Bug encontrado y corregido: las secciones quedaban invisibles porque los reveals dependían de `IntersectionObserver`. Se documentó como regla en la [decisión 004](../03-decisiones/004-animaciones-vanilla.md).
3. **Rúbrica ISI802** revisada y cruzada con el plan ([rúbrica](../01-proyecto/rubrica.md)). Cambios que provocó:
   - Perfil híbrido Software & Datos.
   - Página propia para el caso Colchagua.
   - Power BI por descarga más un dashboard web ([decisión 006](../03-decisiones/006-power-bi-descarga.md)).
   - Formulario con n8n.
   - Página de uso de IA.
   - Lint, tests y Lighthouse.
4. **Repositorio:**
   - `VincentPelos/vduarte.dev` creado como privado, con `develop` como rama por defecto y solo merge commits.
   - 14 labels, 7 milestones y 9 issues de v0.1.0.
   - Identidad de commits: *Vicente Duarte* con el correo noreply de GitHub. El commit inicial se reescribió antes de que existiera más historia.
5. **Bóveda de documentación** (issue #2): esta carpeta.
