# 2026-10-07

## Release v0.2.0

El release de **v0.2.0 Contenido** había quedado pendiente el 2026-10-06 por la red inestable (npm y GitHub fallaban). Hoy se publicó: PR de preparación a `develop` (versión, changelog, índice) y luego `develop → main`, tag `v0.2.0`, GitHub Release y cierre del milestone.

También se corrigió en [tokens](../04-diseno/tokens.md) la ruta de las etiquetas terminales: `src/content/*.json` (antes decía `src/data/`).

**Decisiones de la sesión:**

- **Animación del hero provisional:** el autor pidió copiar la del mockup, pero probablemente cambie. Por eso el hero no depende de ella: tiene fondo de respaldo y la escena se monta aparte en v0.4.0.
- **Todo el texto en JSON:** etiquetas, títulos de sección y singular/plural viven en `site.json`, no en los componentes.
- **Íconos:** `@iconify/utils` + `@iconify-json/simple-icons` en vez de astro-icon (lo que preveía `stack.md`), por tener menos dependencias.
- **Revisión visual:** Edge headless no baja de ~500 px de ancho; las capturas de 390 px se hacen dentro de un iframe.

**Incidencias:** GitHub rechazó por un rato los push y las ediciones de issues (error 500); se reintentó cuando volvió. Al detener el servidor de vista previa se cerraron por error todos los procesos de Node del equipo; desde entonces se detiene solo el proceso del puerto de la vista previa.
